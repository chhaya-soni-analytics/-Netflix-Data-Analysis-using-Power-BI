# 📊 Netflix Data Analysis Dashboard 

## 📌 Overview

This project presents an interactive Tableau dashboard analyzing Netflix movies and TV shows. It provides insights into content distribution, ratings, genres, and trends over time.

---

## 🎯 Objectives

* Analyze Netflix content dataset
* Identify trends in movies and TV shows
* Visualize genre popularity and ratings
* Explore global content distribution

---

## 📂 Dataset Features

* Title
* Type (Movie / TV Show)
* Genre
* Country
* Release Year
* Rating
* Duration
* Date Added

---

## 📊 Dashboard Insights

### 🌍 Country-wise Distribution

* USA has the highest number of titles

### ⭐ Ratings Analysis

* TV-MA and TV-14 are the most common ratings

### 🎬 Content Split

* Movies: 68.42%
* TV Shows: 31.58%

### 🎭 Top Genres

* Documentaries
* Stand-Up Comedy
* Drama

### 📈 Yearly Trends

* Significant growth after 2015
* Peak around 2019
